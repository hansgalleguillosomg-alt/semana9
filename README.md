# SimpleMultimediaApp

Actividad 2.4: Elementos multimedia (Android, Java).

- Imagen (`ImageView`) desde `res/drawable`.
- Audio con `MediaPlayer` (`res/raw/audio_demo.wav`) mediante botón.
- Video con `VideoView` (`res/raw/video_demo.mp4`) mediante botón.
- Animación fade in (`res/anim/fade_in.xml`) aplicada a la imagen.
- Permisos en tiempo de ejecución con `ActivityCompat.requestPermissions` y `onRequestPermissionsResult`.
